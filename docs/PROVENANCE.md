## 5. 结论

| 问题 | 结论 |
| --- | --- |
| 我们是否有权对素材施加自选 CC 许可？ | **否。** 素材权利属第三方，我们只是获取者。 |
| 上游允许的许可范围是什么？ | 形象链上游声明为 **CC BY-NC-SA 4.0（非商业 + 相同方式共享）**；直接来源（§2）**未授予任何许可**且标记禁止转载。 |
| 因此本项目采用？ | 代码 `AGPL-3.0-or-later`；主题美术（形象链的演绎作品）与本项目原创文档 `CC-BY-NC-SA-4.0`；**Windows 原始素材不入库、不转发**。 |
| 转换后的主题能否对外分发？ | **可以（限非商业）**：`CC BY-NC-SA 4.0` 本身**允许**分发与改编，条件是**署名 + 相同方式共享 + 非商业**。项目据此发布，并如实声明直接来源未确认（见 [ATTRIBUTION.md](../ATTRIBUTION.md) §3）。 |
| 能否商用 / 进发行版官方仓库？ | **不能**：许可链为 NC×SA，不满足自由软件定义（DFSG/OSI）。**不得**作此声称。 |
