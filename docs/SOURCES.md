# 素材来源与许可总表（Sources）

本仓库的每个光标主题都是**第三方美术作品的演绎作品**：只做格式转换（Windows 动画光标 `.ani` → XCursor），
不改动角色美术，也不新增动作。**不同来源的许可条件不同，因此必须逐个标注，不能一概而论。**

每个主题目录内都有一份 [`ATTRIBUTION.md`](../themes)（随主题一起分发，不得删除），本文件是汇总视图。

> 取证方式：B 站视频简介、上游仓库的 `ASSET_LICENSE.md` / `LICENSE-CODE` / `README`。
> 所有链接均已剥离跟踪参数（`spm_id_from`、`vd_source`、`share_session_id` 等）。
> 未核实项与残余风险见 [PROVENANCE.md](PROVENANCE.md) 与 [THIRD-PARTY.md](../THIRD-PARTY.md)。

## 2. 许可分组与各自义务

### 2.1 `ZipZipPipe 非商业`（**9 个主题**：ClaudeOpus / ClaudeSonnet / ClaudeFable / Gemini / GLM / Grok / Kimi / Qwen / Seedream）

角色造型来自 **ZipZipPipe** 的原始图库 <https://www.pixiv.net/artworks/148186519>（Claude 设定、Gemini 第 5 页、
Kimi 第 6 页、GLM 第 7 页、Grok 第 8 页、Seedream 第 11 页、Qwen 第 13 页）。该图库的公开条件是：
**允许保存、使用，须注明作者，禁止商业使用**。上游仓库据此制作了新增 Q 版动作，并声明"同样只用于非商业社区分享"。

义务：

- 署名原作者 **ZipZipPipe** 并保留图库地址；
- **禁止任何商业使用**，不得二次贩卖；
- 上游**没有授予再许可**：本仓库按"非商业社区分享"分发转换结果，属推断而非明确授权，**残余风险如实声明**；
- 同一非商业条件必须传递给下游。

> `ClaudeFable` 的形象在 v1.0.1 依用户提供的全身图重做；上游同时说明**原作者身份并未因用户提供图片而得到
> 额外确认**，故仍沿用来源署名边界与非商业条件（该事实写在该主题的 `ATTRIBUTION.md` 内）。

### 2.2 `上游非商业·作者未确认`（**2 个主题**：`MiMo`、`Doubao`）

这两个主题**不能**并入 2.1：上游对它们的角色来源做了明确排除，仓库不得替其"补一个作者"。

| 主题 | 上游原文（`ASSET_LICENSE.md`） |
| --- | --- |
| `MiMo` | 「目前未确认这一具体造型的原始插画作者，**不将它标注为 ZipZipPipe 已确认作品**」 |
| `Doubao` | 「豆包：**用户提供的**短发全身参考…App 头像作为发型对照」；同段重申"不作已确认作者的表述" |

义务：

- **不得**把角色署名给 `ZipZipPipe` 或任何未经确认的作者；分发时必须原样保留"原作者未确认"这一事实；
- 上游对**新增动作**仍声明为"仅用于非商业社区分享"，本主题沿用：**禁止任何商业使用**；
- 权利人一旦主张权利，**立即移除**。

### 2.3 `大肥鱼项目署名许可 1.0`（`DeepSeekWhale`）

角色素材来自 **YunYueSama** 的 [codex-deepseek-pet](https://github.com/YunYueSama/codex-deepseek-pet)，
采用其自定义的「大肥鱼项目署名许可 1.0」：**允许使用、修改、分享，也允许含商用的使用**，
条件是署名 `作者：YunYueSama` + `仓库：https://github.com/YunYueSama/codex-deepseek-pet`，
并在分发实质部分时保留**完整许可文本**（因此主题目录内附 [`LICENSE-ART.txt`](../themes/DeepSeekWhale/LICENSE-ART.txt)）。

义务：保留上述两项署名 + 完整许可文本；说明经过修改；不得暗示原作者或 DeepSeek 官方认可本衍生作品。

**商用余地的边界（重要）**：上游 `ASSET_LICENSE.md` 明说其多批社区参考图"原作者与授权尚待核实"，
"不能仅凭本仓库的署名许可将其视为可自由转载或商用的原创素材"。因此该许可**只及于上游有权授权的部分**，
本仓库不对本主题整体可商用作任何声称。

### 2.4 `未确认`（`ChatGPTDragon`、`AstraMint`、`SolMint`）

这三个主题的上游**没有给出可依据的素材许可**：

- `chatgpt-dragon-cursors`：上游自述参考图署名 `@光影随云飞`，但**明确表示原作者身份与授权范围尚未确认**；
- `astra-sol-mint-cursors`：仓库**没有素材许可文件**（只有代码 MIT），视频简介称角色形象为本地模型 Q 版重绘，
  视频简介提及 `ZipZipPipe`，但"尚未逐张确认原图作者"。

按 [AGENTS.md](../AGENTS.md) §8.3，本应默认不收录无法确认权属的演绎作品；**收录是项目所有者明确决定的结果**，
理由与前提是：上游仓库为公开发布、声明为社区非商业分享。因此本仓库：

- 在这三个主题内与总表中**显著标注"权利未确认"**，不声称获得任何授权；
- **禁止商业使用**；
- 权利人一旦主张权利，**立即移除**（流程见 [THIRD-PARTY.md](../THIRD-PARTY.md) §5）。
